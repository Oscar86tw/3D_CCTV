# 3D-Architectural-Design-CCTV-v1

昱拓弱電有限公司｜社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1.16

### 本版重點
- B1 / B2 圖面已歸類到「樺龍潮+ 社區」
- 支援社區資料夾與樓層圖面管理
- 支援兩點實尺校正
- 鏡頭可直接拖曳移動，勾選固定後不可再移動
- 柱子 / 牆體 / 汽車 / 機車 模組都可直接拖曳移動，勾選固定後不可再移動
- 鏡頭焦距可選：2.8mm、3.6mm、4mm、6mm、8mm
- 鏡頭顏色可選：紅、藍、橘、黃、綠、紫、灰
- 顏色預設分類：原建置=紅、增設=黃、故障=橘
- **藍色與黃色分類已對調**：黃色代表增設；藍色回到一般藍色分類
- **原本藍色提示氣球改為 7 公尺高的黃色無敵星提示，並會閃爍**
- 牆體可用折線方式建立，點回起點可自動完成封閉牆體，並以連續牆面呈現
- 鏡頭視角以單色光影顯示實際可視範圍
- 牆體、柱子、汽車、機車都可阻擋鏡頭視角，形成缺角死角
- 汽車 / 機車模組外型為更接近實感賽車遊戲風格的 3D 造型
- **汽車模組主色由紅色調整為白色**，降低圖面干擾，便於搭配平面圖閱讀
- 汽車 / 機車可勾選是否遮擋鏡頭視角
- 取消勾選後，該車輛不參與鏡頭遮擋計算，適用於鏡頭架設較高、可越過車輛看見後方的場景
- 項目清單可依鏡頭 / 牆體 / 柱子 / 汽車 / 機車 / 全部做分類篩選
- 可建立資料夾、選擇儲存位置、儲存 / 讀取 / 刪除專案
- 支援匯出 / 匯入 `.utop3d` / `.json`
- 每次更新同步更新網頁可見版本號、README 與壓縮檔版本號

## 比例說明
- 圖面 X / Z 採同一縮放係數映射，不拉伸圖紙比例
- 兩點實尺校正後，可把圖上單位換算成實際公尺
- 鏡頭可視範圍遮擋運算，會依牆體、柱子、汽車、機車外框進行裁切
- 若車輛取消「遮擋鏡頭視角」，則不會被納入遮擋計算
