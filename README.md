# 3D CCTV 編輯器 V2.0

GitHub： https://github.com/Oscar86tw/3D_CCTV  
Google Drive 根資料夾： https://drive.google.com/drive/folders/14XSbHur93Q_RmNas8gcfBsRNVGO_OhPR?usp=drive_link

此版本先完成「編輯介面」骨架與基本 CCTV 3D 配置。

## 已完成
- 專案中心：建立 / 開啟 / 刪除 / 匯入 / 匯出專案
- IndexedDB 本機儲存
- 樓層 / 場景：RF、R1F、1MF、1F、2F、3F、B1～B6、自訂
- 左右面板可各自收合
- 專注模式，3D 工作區可接近全畫面
- PDF / JPG / PNG / WebP / DXF 平面圖匯入
- DWG 提示轉 DXF / PDF
- CCTV 鏡頭新增、拖曳、狀態、焦段、方向、距離、高度、固定、視野、備註
- 標記新增、拖曳、類型、內容、是否在使用者介面顯示
- 3D / 俯視 / 縮放 / 全螢幕
